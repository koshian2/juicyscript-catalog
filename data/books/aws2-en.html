Finally make sense of AWS networking — and build infrastructure you can explain with confidence.

This is a hands-on guide to the most essential AWS services — VPC, EC2, and Application Load Balancer — built as code with Terraform. It is for readers who want to really understand AWS networking, not just get it to work.

What makes this book different

Networking is the biggest wall in learning AWS. Subnets, route tables, security groups... Have you ever thought, "I just want to launch one EC2 instance — why do I need all these steps?" This book answers those questions one at a time. It does not just show you how to write the code. It explains why each part of the architecture is there.

Generative AI can now write Terraform code for you. What it cannot do is take responsibility for your design — that is still a human job. The author holds all 12 AWS certifications and keeps the book closely aligned with the official AWS documentation. By the end, you will be building infrastructure that is secure, scalable, and easy to explain — not something that just happens to work.

How the book progresses

The book builds one system step by step, as you would in a real project. It starts with CIDR design, a common stumbling block for beginners, and sets up secure access with Session Manager — no open SSH ports. You then attach EC2 instances to an ALB and publish a web application, and add an Auto Scaling group so the number of servers grows and shrinks with demand. After load testing with Locust, you finish by putting CloudFront in front for faster, safer content delivery.

What you'll learn

Volume 2 walks through 55+ hands-on examples, including:

  • VPC and EC2 fundamentals — subnets, route tables, security groups, and connecting to EC2
  • Practical VPC and EC2 patterns — private subnets, NAT gateways, VPC endpoints, Session Manager, EFS, VPC peering, and Flow Logs
  • Elastic Load Balancing — ALB, target groups, health checks, Route 53, ACM certificates, internal ALBs, NLB, PrivateLink, and VPC Lattice
  • Auto Scaling — launch templates, scaling policies, custom metrics, predictive scaling, and load testing with Locust
  • Amazon CloudFront — S3 and ALB origins, cache policies, custom domains, WAF, Lambda@Edge, CloudFront Functions, and VPC origins

Who this book is for

  • Engineers who have used EC2 or VPC "by feel" and want to understand them properly
  • Anyone moving toward containers or AI/ML — they all run on top of VPC
  • Readers of Volume 1 who are ready to step into real infrastructure

Do I need Volume 1?

No. Volume 1 covered managed services such as Lambda and S3, where AWS runs the infrastructure for you. This volume covers the network layer that you manage yourself, and it is written to stand on its own — you can start here.
